# 快速开始

如果你只是想先把项目跑起来，优先部署或启动 `web/` 前端。

## Vercel 部署

在 Vercel 中导入仓库即可，根目录 `vercel.json` 会构建 `web/`。如果使用 CQ AI Club 账号服务模式，需要在 Vercel 项目中配置下方 `VITE_*` 构建变量，并将 Vercel 域名加入 Logto 回调地址和 Account Service 的 CORS 白名单。

## 本地启动

```bash
git clone git@github.com:g-dxw/lingweave.git
cd lingweave
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建镜像：

```bash
docker build -t lingweave .
docker run --rm -p 3000:3000 lingweave
```

## 首次使用建议

- 账号服务模式下，从顶部账户入口登录 CQ AI Club，打开“配置”点击“拉取模型”，再到“模型”中选择默认模型。
- 未启用账号服务模式时，打开“配置”填写自己的 `Base URL` 和 `API Key`，再拉取并选择默认模型。
- 如果需要提示词仓库内容，打开 `/prompts` 会由浏览器前端直连拉取并缓存到 IndexedDB。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 当前画布项目和“我的素材”主要保存在浏览器本地，WebDAV 同步需要用户自行配置。
- 账号服务模式下，浏览器使用 Logto Access Token 请求 Account Service，由服务端代理 NewAPI；本地回退模式下，AI API Key 保存在浏览器本地并由前端直接请求兼容接口。
