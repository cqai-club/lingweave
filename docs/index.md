## 说明

- 当前画布项目和“我的素材”主要保存在浏览器本地，跨设备可自行配置 WebDAV 同步。
- 配置 Account Service 时，浏览器使用 Logto Access Token 请求账号服务，由服务端代理 NewAPI；未配置时才由浏览器直接使用本地 Base URL 和 API Key 请求 OpenAI 兼容接口。
